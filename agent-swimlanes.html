Work acceptance loop

Assigned step → worker tests → durable handoff → CTO + CPO independently → fixes if required → manager integration checks → update plans and ledger → evaluate → publish.

Unit contracts, actual source adapters and browser journeys have separate acceptance boundaries. A worker saying “done” is a review trigger, not a release verdict.
